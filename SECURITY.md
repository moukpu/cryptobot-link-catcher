# Безопасность

Никогда не публикуйте `.env`, Telegram session-файлы, резервные копии,
SQLite-базу, логи и приватный SSH-ключ.

Доступ к панели проверяется по числовому Telegram ID и разрешён только в личном
чате. По умолчанию ID берётся из авторизованной пользовательской сессии.

После первой авторизации поле `PHONE_NUMBER` можно очистить. Для отзыва доступа
остановите сервис, завершите соответствующую Telegram-сессию в настройках
аккаунта и замените BotFather-токен.
